# Мозаика

Клиент-серверное приложение для публикации изображений и обмена сообщениями.
Протокол HTTP/1.1 реализован самостоятельно поверх TCP-сокетов: без Flask,
Django, `http.server`, `requests` и других веб-библиотек. Сервер использует
только стандартную библиотеку Python 3.10+.

## Возможности

- регистрация и вход, сессии на cookie (`HttpOnly`, `SameSite=Lax`, 7 дней);
- загрузка изображений JPEG, PNG, GIF, WEBP до 5 МБ с проверкой сигнатуры;
- общая лента с мозаичной раскладкой и постраничной выдачей;
- лайки и снятие лайков без перезагрузки страницы;
- просмотр фотографии крупным планом, скачивание файла и комментарии;
- удаление своей публикации вместе с файлом (кнопка «Удалить» в окне фото);
- поиск людей по логину и имени, а также публикаций по подписи;
- личные сообщения: диалоги, счётчик непрочитанных, отметка о прочтении,
  обновление опросом раз в 3 секунды;
- профиль автора со списком его публикаций (пункт «Профиль» в шапке);
- три журнала (`access`, `server`, `audit`) в консоли и в `server.log`;
- консольный клиент на голых сокетах `client_raw/raw_client.py`.

## Требования

- Windows 10/11 (проверено), Linux/macOS — при наличии Python 3.10+;
- Python 3.10 или новее;
- браузер Chrome/Edge/Firefox 90+;
- для тестов — `pytest`, для сборки документов — `python-docx` и `matplotlib`.

Сервер не требует установки пакетов: `pip install` для запуска не нужен.

## Быстрый старт

> Подробная пошаговая инструкция «для чайников» — в файле
> [docs/Как_запустить.md](docs/Как_запустить.md): запуск на одном ПК,
> подключение телефона и второго ноутбука, проверка функций,
> разбор типичных ошибок.

```bat
cd путь\к\pinterest
py server/main.py --host 0.0.0.0 --port 8000
```

Или двойным щелчком по `scripts\run_server.bat` — файл включает UTF-8
и сам находит `py` или `python`.

Откройте `http://127.0.0.1:8000`. При первом запуске база создаётся
автоматически, лента пуста.


Скрипт создаёт двух пользователей, шесть публикаций с картинками
(генерируются встроенным PNG-кодировщиком), комментарии и переписку.
В демо-базе только два аккаунта — авторы работы. Пароль: `secret123`.

| Логин | Имя |
|---|---|
| `ksenia` | Ксения Дутикова |
| `artem` | Артём Панов |

У Ксении три публикации, у Артёма три, между ними — переписка и
комментарии к фотографиям.

**Данные не пропадают при перезапуске.** База лежит в
`storage/mosaic.db`, фотографии — в `storage/uploads/`. Команда
`--reset` больше ничего не удаляет: старая база сохраняется рядом как
`storage/mosaic-backup-<дата>.db`, а загруженные файлы остаются на месте.
Вернуть старую базу можно, переименовав бэкап обратно в `mosaic.db` при
остановленном сервере.

## Запуск на двух ноутбуках

1. Ноутбук 1 (сервер):

   ```bat
   py server/main.py --host 0.0.0.0 --port 8000
   ```

   В консоли появятся адреса вида `http://192.168.0.10:8000`.

2. Разрешите входящие подключения на порт 8000 — проще всего двойным
   щелчком по `scripts\allow_firewall.bat` (подтвердите запрос администратора).
   Ещё проще: `scripts\start_server_public.bat` — он сам добавит правило
   и запустит сервер в одном окне.
   Или вручную от имени администратора:

   ```bat
   netsh advfirewall firewall add rule name="Mosaic 8000" dir=in action=allow protocol=TCP localport=8000
   ```

3. Узнайте IP сервера: `ipconfig` → «IPv4-адрес».

4. Ноутбук 2: откройте `http://<IP>:8000` в браузере.

5. Если страница не открывается — проверьте `ping <IP>`. При изоляции
   клиентов в Wi-Fi используйте точку доступа телефона или кабель.

Проверить, что порт слушается: `netstat -ano | findstr :8000`.

### Доступ из интернета (не обязательно)

По умолчанию сайт доступен только в локальной сети — публичного адреса
у него нет. Если нужно показать его устройству в другой сети, можно
поднять туннель, например бесплатный `cloudflared`:

```bat
cloudflared tunnel --url http://127.0.0.1:8000
```

Команда выдаст публичный HTTPS-адрес вида `https://...trycloudflare.com`,
который ведёт на ваш локальный сервер. Учтите: ссылка будет доступна
любому, кто её знает, поэтому после демонстрации туннель нужно закрыть
(Ctrl+C). Для курсовой это не требуется — достаточно двух устройств
в одной сети.


## API

Все ответы — JSON в UTF-8, ошибки — `{"error": "текст"}`.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/register` | Регистрация |
| POST | `/api/login` | Вход, `Set-Cookie` |
| POST | `/api/logout` | Выход |
| GET | `/api/me` | Текущий пользователь |
| GET | `/api/feed?limit=&offset=&author=` | Лента |
| POST | `/api/posts` | Загрузка (multipart) |
| GET | `/api/posts/{id}` | Полная карточка публикации |
| POST | `/api/posts/{id}/like` | Лайк / анлайк |
| GET | `/api/posts/{id}/comments` | Комментарии |
| POST | `/api/posts/{id}/comments` | Добавить комментарий |
| GET | `/api/posts/{id}/download` | Скачать фото |
| POST | `/api/posts/{id}/delete` | Удалить свою публикацию |
| GET | `/api/users?q=` | Поиск людей |
| GET | `/api/search?q=` | Поиск людей и подписей |
| GET | `/api/messages` | Диалоги |
| GET | `/api/messages/{username}?after_id=` | Переписка |
| POST | `/api/messages/{username}` | Отправить сообщение |
| POST | `/api/messages/{username}/read` | Отметить прочитанным |
| GET | `/uploads/{file}` | Изображение |
| GET | `/`, `/login`, `/static/{file}` | Страницы и ресурсы |

Пример запроса:

```bat
curl -i -X POST http://127.0.0.1:8000/api/login ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"ksenia\",\"password\":\"secret123\"}"
```

```bat
py client_raw/raw_client.py login ksenia secret123
py client_raw/raw_client.py feed
py client_raw/raw_client.py send artem "Привет!"
```

## Ограничения

- только GET и POST, без chunked, keep-alive и HTTPS;
- одно соединение — один запрос, `Connection: close`;
- сообщения доставляются опросом, а не через WebSocket;
- один процесс сервера, SQLite без репликации;
- расчёт на локальную сеть и учебную нагрузку (десятки клиентов).

## Типовые проблемы

| Симптом | Решение |
|---|---|
| `Не удалось занять 0.0.0.0:8000` | `--port 8001` или завершить процесс из `netstat` |
| Страница не открывается с другого ПК | запустите `scripts\check_network.bat`: он покажет адрес, правило и доступность |
| Вместо русского текста — символы | `run_server.bat` или `set PYTHONUTF8=1` |
| Старая версия JS | Ctrl+F5; сервер отдаёт `Cache-Control: no-store` |
| `database is locked` | остановить второй экземпляр сервера |
