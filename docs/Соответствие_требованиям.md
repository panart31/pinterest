# Соответствие требованиям

Проверка выполнена по исходному заданию на курсовую работу. Для каждого
пункта указано, чем он подтверждается. Команды приведены для Windows.

## 1. Технологические ограничения

| Требование | Статус | Подтверждение |
|---|---|---|
| Python 3.10+ | выполнено | `py -V` → 3.14.6; код не использует синтаксис новее 3.10 |
| Только стандартная библиотека в рантайме | выполнено | импорты сервера: `socket`, `threading`, `sqlite3`, `hashlib`, `secrets`, `json`, `uuid` |
| Запрещённые библиотеки отсутствуют | выполнено | поиск по `server/`, `client_raw/`, `web/` не находит `http.server`, `socketserver`, `flask`, `django`, `fastapi`, `requests`, `urllib.request`, `httpx` |
| Сокеты вручную | выполнено | `server/core/server.py`: `socket`, `setsockopt`, `bind`, `listen`, `accept`, `recv`, `sendall`, `close` |
| HTTP/1.1 реализован самостоятельно | выполнено | `server/http/request.py`, `response.py`, `multipart.py`, `router.py` |
| Клиент — SPA + сырой сокетный клиент | выполнено | `web/`, `client_raw/raw_client.py` |
| Запуск без `pip install` | выполнено | `py server/main.py --port 8000` на чистой установке Python |
| Интерфейс и документация на русском | выполнено | все страницы, сообщения и документы |
| pytest только для тестов | выполнено | `pytest` не импортируется сервером |

**Объём.** Фактически 56 страниц (проверено рендером LibreOffice),
из них приложения — 3 страницы. Это больше плановых 33–38 страниц.
Причина — 18 рисунков, 9 таблиц и 13 листингов: только они занимают
около 15 страниц, а текстовая часть — примерно 30 страниц. Если
требуется строго уложиться в 38, можно убрать 3–4 скриншота и 4–5
листингов без потери обязательных элементов; это даст около 42 страниц,
дальнейшее сокращение потребует убрать часть содержательных разделов.

## 11. Что осталось сделать вручную

1. Вписать название кафедры на титульном листе.
2. Открыть документ в Word и обновить оглавление (F9) — кэш уже заполнен,
   но Word пересчитает номера под свою вёрстку.
3. Доснять кадры, которые нельзя сделать автоматически: структура проекта,
   консоль запуска, `netstat`, два ноутбука, Wireshark, `pytest -v`.
4. Проверить демонстрацию на двух ноутбуках и правило брандмауэра.

## 12. Известные ограничения

- Объём 56 страниц вместо плановых 33–38 (см. пояснение выше).
- Отдельные модули длиннее рекомендованных 200 строк: `repository.py`
  (275), `request.py` (253). Дробление ухудшило бы связность слоя.
- 403 объявлен в списке статусов, но в текущем функционале не используется.
- Сообщения доставляются опросом, а не через WebSocket; HTTPS не поддержан.
