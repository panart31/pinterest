Автоматические скриншоты лежат в `docs/screenshots`. Кадр пустой ленты
снимается на втором, чистом экземпляре сервера (порт 8001), который
скрипт поднимает и останавливает сам. Все кадры снимаются командой:

```bat
py -m pip install websocket-client
py scripts/take_screenshots.py
```

Скрипт сам поднимает сервер, наполняет базу демо-данными и управляет
headless Edge через DevTools Protocol. Профиль браузера создаётся
во временном каталоге и не мешает рабочему.

## Как снимать вручную

### 1. Структура проекта

Откройте корень проекта в проводнике, включите отображение дерева
слева (Вид → Область навигации → Панель навигации). Разверните `server`
и `web`, чтобы были видны модули. Снимок — весь экран проводника.

### 2. Консоль запуска сервера

```bat
cd путь\к\pinterest
scripts\run_server.bat
```

Дождитесь баннера: локальный адрес, адрес в сети, пути к базе и файлам.
Снимок — окно консоли целиком, без обрезки верхней строки.

### 3. Порт слушается

Во втором окне консоли:

```bat
netstat -ano | findstr :8000
```

В выводе должна быть строка `LISTENING` с PID. Снимок — окно с командой
и результатом.

### 6. Пустая лента

Кадр уже снят автоматически (`10_empty_feed.png`): скрипт поднимает второй
сервер на порту 8001 с чистой базой, регистрирует пользователя и фотографирует
пустую ленту. Если нужно повторить вручную — остановите сервер, переименуйте
каталог `storage` в `storage_backup`, запустите сервер и зарегистрируйтесь.
После снимка верните каталог на место.

### 12. Два ноутбука рядом

Поставьте ноутбуки экранами к камере так, чтобы на обоих был виден
интерфейс: слева — сервер и его консоль, справа — лента с загруженной
карточкой. Снимите на телефон или камеру, чтобы в кадр попали оба экрана
и было понятно, что это разные машины. Лица людей и посторонние окна
в кадр не включайте.

### 13. Журнал сервера

Отправьте с клиента 5–6 запросов (обновите ленту, поставьте лайк,
отправьте сообщение) и снимите консоль сервера. В строках должны быть
видны разные коды: 200, 201, 401. Хорошо, если в кадр попадёт и
`server.log` в редакторе — но достаточно консоли.

### 18. Просмотр фото с комментариями

Кадр снимается автоматически (`11_post_view.png`): скрипт открывает первую
карточку ленты, ждёт загрузки комментариев и фотографирует модальное окно.
Вручную: войдите, щёлкните по любой фотографии и добавьте комментарий.

### 14. Консольный клиент

```bat
py client_raw/raw_client.py login ksenia secret123
py client_raw/raw_client.py feed
py client_raw/raw_client.py send artem "Привет с защиты"
```

Снимите окно, где видны команда, код ответа и JSON. Одного кадра с `feed`
достаточно; `login` добавляет доказательство работы cookie.

### 15. Wireshark

1. Запустите Wireshark, выберите интерфейс с трафиком (Wi-Fi или Ethernet).
2. Фильтр: `tcp.port == 8000`.
3. С клиента обновите ленту.
4. Остановите захват, найдите пакет `POST /api/posts` или `GET /api/feed`.
5. Правый клик → Follow → TCP Stream.

Сделайте два кадра: список пакетов с фильтром и окно Follow TCP Stream,
где видны строка запроса и заголовки. Для загрузки изображения в потоке
будут видны `multipart/form-data` и boundary.

### 16. pytest

```bat
py -m pytest -v
```

Снимите последние 10–15 строк: список тестов и итоговую строку
`79 passed`. Лучше запускать в окне с достаточной высотой, чтобы
итог и часть имён тестов попали в один кадр.

### 17. Ответ 401

Вариант через браузер: выйдите из системы и откройте
`http://127.0.0.1:8000/api/feed` — браузер покажет JSON с ошибкой.
Вариант через curl:

```bat
curl -i http://127.0.0.1:8000/api/feed
```

Снимите строку статуса `HTTP/1.1 401 Unauthorized` и тело ответа.
Готовый кадр `09_api_401.png` сделан первым способом.

## Требования к кадрам

- формат PNG, ширина не меньше 1280 px;
- масштаб интерфейса 100 %, без обрезки заголовков и подписей;
- на кадре нет личных файлов, переписок и уведомлений;
- тёмная тема не используется — документ оформлен в светлых тонах;
- подпись в документе: «Рисунок N – Название», ссылка в тексте обязательна.
